## About me 👋
I'm Nelson, a 2nd year CS student. I'm passionate about backend development and workflow efficiency. Some of my other interests are Linux, homelabbing, and Artificial Intelligence.

## My Projects
I'm currently working on creating an API and several clients to facilitate the process of searching for classes @ HCC. The repo will be posted soon! In the meantime, these are some of my other public projects:

- **[nixos-config](https://github.com/HefKer/nixos-config)**: My system configurations using [NixOS](https://nixos.org/), a Linux distribution focused on reproduceability. It allows me to port all my programs and system configurations to a new computer in a matter of minutes.
- **[dots](https://github.com/HefKer/dots)**: My "dotfiles," in other words settings for all the programs I use on linux - including my code editor, browser, terminal, shell and more.
